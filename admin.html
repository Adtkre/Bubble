Vercel & Database Infrastructure

Bubble uses a dual-engine database architecture designed for instant local development and scalable Vercel cloud deployment.

Deploying to Vercel

1. Push code to GitHub and link repository on Vercel.
2. On Vercel dashboard, go to Storage and create a Postgres (Neon) database.
3. Vercel automatically sets POSTGRES_URL environment variable, activating the SQL engine.

Local Development Mode

When running locally with npm start without Postgres credentials, the engine persists data directly to data/bubble_db.json, keeping your accounts and audit logs completely functional offline.
