How Bubble Works

A Developer Environment Built for Beginners

Bubble doesn't hide the code behind proprietary walls. It connects visual blocks, live mobile rendering, and standard Dart code into one cohesive learning loop.

1. Connect Visual Blocks

Snap together statements, variables, logic branches, and Flutter widgets with zero syntax errors. Puzzle notches ensure only compatible blocks connect.

2. Live Mobile Simulator

Watch your mobile app respond in real-time inside a realistic phone frame. Tap buttons, input text, and trigger state changes instantly.

3. Learn Real Dart Code

Bubble translates your block programs into clean, standard Flutter main.dart code with source-mapping highlights and guided explanations.

Frequently Asked Questions

Everything You Need to Know

What are Flutter and Dart?

Flutter is Google's open-source UI toolkit for building natively compiled, cross-platform apps for mobile (iOS & Android), web, and desktop from a single codebase. Dart is the client-optimized, object-oriented programming language created by Google that powers Flutter. Bubble bridges visual block-based building with Flutter and Dart, letting you design visually while producing real, exportable Flutter code.

Do I need to install Flutter or an Android SDK to use Bubble?

No! Bubble runs 100% inside your web browser. You can design apps, connect blocks, and run the mobile simulator without installing anything.

Can I export real Dart code to run on my actual phone?

Yes! With one click you can download main.dart and open it in VS Code or Android Studio to compile it for iOS and Android.

Where are my projects saved?

All your projects are saved privately in your browser's Local Storage. You can also export and import full JSON project backups anytime.
